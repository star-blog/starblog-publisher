# 站点文章工作区

站点文章负责线上文章与草稿的查看、更新和维护；本地新建、首次发布和添加分类继续使用「文章」工作区。

## 页面布局

- 左侧筛选栏：输入关键词后点击搜索或按 Enter；发布状态和分类即时筛选，清除筛选一次重置全部条件。
- 右侧文章库：展示标题、分类、状态和最近更新时间。选中文章后点击「编辑文章」，也可双击或按 Enter。底部提供分页和请求状态。
- 未登录、站点无文章、筛选无结果和请求失败分别显示提示；未登录可直接登录，失败可重新加载。

列表、线上编辑和分类管理共用紧凑工具栏、主题色、分隔线及状态栏，适配 800 像素及以上窗口宽度。

## 线上编辑

正文使用与本地工作区相同的 AvaloniaEdit 和 Markdown 语法高亮，支持 Ctrl+F 搜索。顶部编辑器选项控制自动换行与行号。右侧属性栏提供标题、分类、摘要和 Slug，正文和属性栏间可拖动调整宽度。

属性栏底部的「更新文章 / 发布文章」调用已有文章的 Update；「存为草稿」会将文章设为未发布，包括原本已发布的文章。状态栏显示是否存在未保存修改，通过面包屑返回列表前会确认放弃修改。

属性栏更多菜单提供浏览器打开、下载、下载后在工作区打开及删除。下载得到的是站点已保存正文，并同时写入包含 postId 的 `.starblog.json`；未保存的线上编辑不会包含在下载文件中。删除继续使用现有确认对话框。

## 分类管理

作为站点文章的二级页面，左侧选择分类，右侧编辑名称与前台可见性，统一通过「保存修改」提交。删除分类前需要确认，服务端会阻止删除仍有文章的分类。

重构后移除了重复的「新建分类」和「切换显隐」操作：添加分类继续使用文章工作区已有的分类选择器，显隐使用同一属性表单保存。Core、CLI 和 MCP 的分类创建能力不受影响。

## 验证

```powershell
dotnet test StarBlogPublisher.Tests/StarBlogPublisher.Tests.csproj
dotnet run --project StarBlogPublisher.DesktopTests -- --site-posts
```

桌面验证使用临时设置和示例文章，不请求真实站点、不发布内容。覆盖未登录提示、列表、线上编辑和分类管理，检查 1280 / 800 像素窗口的滚动布局、浅色与深色主题，以及 Markdown 正文与视图模型之间的双向同步。单元测试覆盖失败提示、加载中切换筛选、清除筛选和删除末页后的重新分页。截图及报告保存在 `output/desktop-tests/`。
