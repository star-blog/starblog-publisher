# 文章工作区

主界面将菜单栏融合到标题栏，提供文件、编辑、查看、文章、发布和帮助六组菜单。标题栏中间可搜索文章或命令，右侧提供布局开关；空白区域支持拖动和双击最大化。窗口较窄时，菜单折叠到左上角的菜单按钮。

文档标签下方是面包屑与紧凑的源码／分栏／预览切换。左侧提供可折叠的已打开、最近打开和文章大纲；点击大纲可跳转到对应章节。右侧文章属性可折叠和拖动调宽，发布目标与操作固定在底部。任务面板位于正文下方，状态栏固定在工作区最底部。

## 文件操作

- `Ctrl+N`：新建文章。
- `Ctrl+O`：打开一篇或多篇 Markdown；也支持拖放 `.md` / `.markdown` 文件。
- `Ctrl+S`：保存正文与文章属性。新建文章首次保存时选择文件位置。
- `Ctrl+Shift+S`：另存为。
- `Ctrl+W`：关闭当前文章。未保存时提供保存、不保存、取消。
- `Ctrl+Tab`：切换到下一个标签。
- `Ctrl+B`：展开或收起文件侧栏。
- `Ctrl+Alt+B`：展开或收起文章属性。
- `Ctrl+J`：显示或隐藏文章任务面板。
- `Ctrl+Shift+F11`：进入或退出专注模式，退出时恢复之前的面板布局。
- `Ctrl+P`：快速打开已打开或最近使用的文章。
- `Ctrl+Shift+P`：打开命令面板；在搜索框输入 `>` 也可切换到命令搜索。
- `Ctrl+F` / `Ctrl+H`：在当前编辑控件中查找／替换，支持区分大小写的文字查找和全部替换。

菜单使用标准菜单控件，可通过 Alt、方向键、Enter 和 Esc 导航；菜单右侧显示快捷键，不满足执行条件的操作置灰。编辑菜单作用于最后获得焦点且仍可见的编辑控件，包括正文、标题与摘要。命令面板支持方向键选择、Enter 执行和 Esc 关闭。

文件菜单还提供最近打开、全部保存和关闭全部文章。标签右键菜单提供保存、另存为、关闭、关闭其他、关闭右侧和复制文件路径。批量关闭在用户取消或保存失败时停止。

同一路径重复打开会切换到已有标签。标签的圆点表示正文或发布属性有未保存修改。关闭最后一个标签返回欢迎页，打开入口始终可用。退出窗口也会检查每篇文章；有发布、保存或 AI 任务正在执行的文章需等待任务完成后关闭。

## 保存与恢复

正文写回原 Markdown 文件。发布标题、摘要、关键词、Slug 和分类保存在同目录的 `文章.md.starblog.json` 中，重新打开文章时一起读取。移动文章时，可同时移动这个属性文件。

最近文件、已打开的文件路径和布局偏好保存在配置目录的 `workspace.json`。通过“文件 → 恢复上次会话”恢复标签及上次选中的文件。恢复读取磁盘上的已保存内容，不包含未保存草稿或退出前的撤销历史。侧栏、任务面板及文章属性面板的显隐和属性面板宽度会被记住。

发布与本地保存分开：发布后服务器返回的正文若有变化，会继续显示未保存标记，需要保存后才写回本地文件。公众号排版和草稿发布仍使用原有流程，可以从发布菜单或左侧公众号入口进入。

右侧选择“微信公众号”后，主按钮会进入公众号排版与草稿流程，不会立即发送。任务面板显示当前打开文章的状态、发布进度及已有发布结果入口；它不是跨会话的任务历史。

## 实现与验证

`ArticleWorkspaceViewModel` 管理标签、最近文件、文件去重和关闭流程。每个标签独立持有 `PublishViewModel`，正文、文章属性、AI 操作、发布进度和发布结果不会因切换标签而混用。编辑视图在标签间复用，各文档独立持有编辑器文档与撤销记录，并在布局完成后恢复光标和滚动位置。

`ShellCommand` 定义全局命令的标识、分组、快捷键和可执行状态，标题菜单、快捷键及命令面板共用这些定义。切换到设置等页面时保留工作区视图，避免反复销毁预览控件。

运行 `dotnet test StarBlogPublisher.Tests/StarBlogPublisher.Tests.csproj` 验证文档隔离、保存与属性恢复、失败处理、关闭选择、并发打开去重、会话与布局恢复、命令路由、搜索筛选和 Markdown 大纲解析。

界面回归检查：打开两篇文章 → 编辑第一篇并滚动 → 切换到第二篇再返回 → 检查光标、滚动与撤销 → 关闭第一篇并分别检查取消、不保存 → 修改第二篇并保存后关闭 → 从欢迎页重新打开。再检查浅色、深色、最小窗口、分栏及预览模式。

## 紧凑文章侧栏

侧栏采用扁平分区与 28 DIP 文件行。顶部提供新建、打开及更多操作；已打开列表显示文件图标、独立的未保存圆点，活动行、鼠标悬停或键盘聚焦时显示关闭按钮。关闭仍执行原有的未保存检查，完整路径可通过悬停查看。

拖动侧栏右边缘调整宽度（180–420 DIP，默认 240 DIP）。宽度与三个分区的展开状态会记住，隐藏侧栏或进入专注模式不会丢失原宽度。

已打开列表最多显示六行，最近打开默认收起、展开后最多显示五行；各自独立滚动。文章大纲默认展开并占据剩余高度，以 H1–H6 与缩进标示层级，点击标题跳转正文。当前版本保留平铺层级导航，标题子树折叠及跟随光标滚动留作后续增强。
